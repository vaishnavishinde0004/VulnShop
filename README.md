# VulnShop

VulnShop is an intentionally vulnerable Flask web application
built as a local laboratory for practicing Web VAPT.

## Purpose

This project is designed for cybersecurity learning and includes
deliberately vulnerable functionality for testing with tools such
as Burp Suite.

## Vulnerabilities

- SQL Injection
- Reflected XSS
- Stored XSS
- Broken Access Control
- Information Disclosure
- Weak Authentication
- Missing CSRF Protection
- Missing Security Headers
- Lack of Rate Limiting

## Warning

This application is intentionally insecure.

Run it only in a controlled local environment.
Do not expose it to the public internet.
